## About

This backend service provides RESTful APIs built with Node.js, TypeScript, and Prisma ORM to interact with a PostgreSQL database. It supports user authentication, product management, orders, and more.

---

## Features

- User registration and authentication
- Product listing and management
- Order processing
- PostgreSQL database with Prisma ORM
- Dockerized for easy development and deployment
- CI/CD ready

---

## Tech Stack

- Node.js
- TypeScript
- Express.js
- Prisma ORM
- PostgreSQL
- Docker
- ts-node-dev for development
